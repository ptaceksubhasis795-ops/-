# 正式联调清单

## 必须由公司提供

- 微信小程序 AppID、Secret、开发者权限和合法 HTTPS 业务域名。
- 微信支付商户号、API v3 Key、商户私钥、平台证书、证书序列号、支付回调域名。
- 商家转账到零钱开通状态和提现收款规则。
- MySQL 账号、数据库地址、备份策略；Redis 地址和访问凭证。
- 腾讯云 COS Bucket、Region、SecretId/SecretKey 或等价对象存储配置。
- 互联网医院、电子发票、物流、短信、ERP、健康管理服务的接口地址、密钥、测试账号和回调说明。
- 处方中药饮片、保健食品、健康信息处理、推广奖励和宣传内容的主体资质。
- 品种奖励清单、运费阈值、税费口径、退款扣奖规则、晋级和解绑的最终业务口径。

## 私密文件位置

- `server/.env`：只保存环境变量，不提交 Git。
- `secrets/wechat-private-key.pem`：微信商户私钥。
- `secrets/wechat-platform-cert.pem`：微信平台证书。
- `server/.env.production.example` 和根目录 `.env.production.example` 只作为模板。

## 联调顺序

1. 执行 `npm run readiness`，确认密钥和接口地址齐全。
2. 配置 MySQL/Redis，执行 `npm run prisma:migrate` 和 `npm run prisma:seed`。
3. 启动 API，检查 `/api/v1/health` 和 `/api/v1/admin/integrations/status`。
4. 配置微信登录、JSAPI 支付、支付通知验签和退款。
5. 联调医院处方、发票、物流、短信、COS 和健康服务接口。
6. 使用 `docs/验收用例.md` 完成真账号回归，确认后才允许发布小程序。

## 禁止事项

- 不把 Secret、私钥、平台证书、数据库密码提交到仓库或聊天记录。
- 不在正式环境使用 `REPOSITORY_MODE=memory` 或演示账号。
- 不在资质和支付配置未完成时开启真实处方支付、提现或宣传推广。
