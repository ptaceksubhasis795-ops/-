# 一期验收用例

## 消费者端

| 编号 | 场景 | 通过条件 |
|---|---|---|
| C-01 | 微信/演示登录 | 成功进入首页，用户身份和会话 token 可读取；演示模式不发送真实数据 |
| C-02 | 普通商品下单 | 购物袋、运费、总额由服务端重算；支付回调重复不会生成重复订单 |
| C-03 | 订单取消 | 30 分钟未支付可被任务接口取消，库存恢复，订单不可再次支付 |
| C-04 | 自动收货 | 发货超过 7 天的订单可被任务接口自动收货 |
| C-05 | 处方上传 | 绑定实名就诊人后上传凭证，处方进入待审核，药师审核后显示支付入口 |
| C-06 | 处方重复购买 | 同一处方已占用或已使用时，服务端拒绝第二次下单 |
| C-07 | 处方取消 | 未支付处方订单取消后，库存恢复，处方恢复审核通过状态 |
| C-08 | 就诊人/健康信息 | 身份证号、手机号展示脱敏；健康信息授权记录可审计 |
| C-09 | 售后/发票 | 普通商品可提交售后；确认收货后可申请电子普通发票 |
| C-10 | 大字模式 | 开关持久化，主要字号和按钮尺寸增大，页面不出现横向滚动 |

## 销售与后台

| 编号 | 场景 | 通过条件 |
|---|---|---|
| B-01 | 推广归属 | 首次推广码绑定客户，销售中心只看到直接客户和必要信息 |
| B-02 | 奖励生效 | 收货后 7 天无售后才进入可结算，退款可以扣回 |
| B-03 | 周结算 | 管理员执行结算任务后，奖励状态变为已结算并写入审计 |
| B-04 | 提现审核 | 低于 500 元拒绝；管理员审核后进入待打款/驳回状态 |
| B-05 | 处方权限 | 会员不能查看处方；药师可审核；销售只看所属客户的必要信息 |
| B-06 | 后台导出 | 只有管理员可导出；默认脱敏；导出动作写入审计日志 |
| B-07 | 第三方兜底 | 医院/发票/物流接口不可用时，后台人工任务仍可推进业务 |
| B-08 | 越权请求 | 生产环境没有有效 Bearer token 时，不能通过请求头伪造管理员角色 |
| B-09 | 后台履约操作 | 订单列表“处理”可发货/确认收货；处方列表“审核”可更新状态；操作结果有提示并刷新数据 |
| B-10 | 商品与内容操作 | 商品库存调整、科普文章/首页轮播、奖励规则和推广归属 API 可写入并留审计 |

## 发布前阻断项

- 微信 AppID、支付商户号、商家转账和 HTTPS 域名未配置时，不得执行真实支付或提现。
- 处方中药饮片销售、保健食品宣传、健康信息处理和推广奖励需完成主体资质及合规审核。
- MySQL、Redis、COS 和第三方服务参数配置完成后，再进行生产环境迁移和压测。
