## 当前上线阻断项

1. 微信 AppID、商户号、API v3 密钥、商家转账权限和合法 HTTPS 域名。
2. 互联网医院、发票、物流、短信、COS、ERP 的供应商参数和联调环境。
3. MySQL 账号与迁移窗口；当前服务端默认内存快照，Prisma 同步路径已接入但未做真实数据库回归。
4. 处方药销售、保健食品宣传、健康信息处理和推广奖励的主体资质与最终业务口径。
