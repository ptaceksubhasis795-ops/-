# 实施计划

1. **数据迁移与兼容层**
   - Prisma 增加归档、晋升申请、奖励规则集合/档位和会员申请字段。
   - 编写迁移与旧 RewardRule/MemberApplication 回填；保留旧接口投影。
   - 扩展 MemoryStore、Prisma hydrate/sync 和演示种子。
2. **服务端闭环**
   - 实现推广人分页、归档删除、历史查询和唯一编号。
   - 实现会员申请状态筛选、强制销售归属审批和晋升申请 eligibility/review。
   - 实现关系树查询、批量绑定/解绑、未绑定客户查询和审计。
   - 实现商品奖励规则集合校验、迁移投影和结算计算适配。
   - 实现小程序 network/eligibility/application 接口。
3. **后台重构**
   - 推广人分页与批量操作。
   - 会员申请三状态 Tab、统一筛选、详情与审核弹窗。
   - 会员晋升申请页面。
   - 关系树销售列表、树详情、拖放/批量绑定。
   - 商品奖励规则搜索预览和整套编辑页。
4. **小程序重构**
   - 晋升申请进度与审批状态。
   - 我的关系页按 member/sales 身份裁剪数据。
   - 会员申请状态和归属展示。
5. **验证与回归**
   - Prisma validate/migrate status、API lint/build。
   - 分页/审批/晋升/归档/关系/奖励规则集成测试。
   - 后台 Playwright 页面、拖放与批量操作测试。
   - 小程序清单、JavaScript 语法和新增页面流程检查。
